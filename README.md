# Qrio Website

Official landing page, Privacy Policy, and Terms of Use for Qrio.

- Production: <https://qrio.microspotlight.team>
- App Store: <https://apps.apple.com/us/app/qrio/id6752806449>
- Source: <https://github.com/MicroSpotlight/qrio-website>

## Development

```sh
npm install
npm run dev
```

## Verification

```sh
npm run build
npm run test:sites
```

The `main` branch deploys `dist/client` to GitHub Pages. The custom domain is
declared in `public/CNAME`.
